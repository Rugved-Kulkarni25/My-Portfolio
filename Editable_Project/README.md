# Rugved Kulkarni — Animated Portfolio

A responsive, animated, fully editable personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or hosting service required.

## How to open it

1. Extract the complete ZIP.
2. Open `index.html` in any modern browser.
3. Keep `style.css`, `script.js` and the `assets/` folder next to `index.html`.

It can also be hosted on GitHub Pages, Vercel, Netlify or any static web server by uploading the complete folder contents. `index.html` must be in the published root.

## What's included

- Responsive hero with your supplied professional portrait
- Typed job descriptions, animated orbit graphics, hover effects, motion-reveal sections and a scroll-progress bar
- Filterable project gallery (AI/vision, research, web/products)
- Experience and leadership timeline
- Education and selected recognitions, including a viewable cropped Vishwakarma Awards Stage 2 announcement
- Skills, résumé download, email copy button, GitHub and LinkedIn links
- Mobile navigation, keyboard accessibility and reduced-motion support
- Color theme toggle (stored locally in your browser)

## Update your information

- **Bio/contact/role/projects:** edit the text and links in `index.html`.
- **Design/colors/animations:** edit `style.css`, especially `:root` variables at the beginning.
- **Project filters/typing/menu/theme:** `script.js`.
- **Portrait:** replace `assets/rugved-portrait.webp` with your own photo, keeping the same name or updating the image `src`.
- **Resume:** replace `assets/Rugved_Santosh_Kulkarni_Resume.pdf`.

## Before you publish

Make sure you're comfortable publishing the contact email and any information on your résumé (which currently contains a personal phone number), test every project link, and update the metadata/social-sharing image to an absolute URL once you have a live domain.
